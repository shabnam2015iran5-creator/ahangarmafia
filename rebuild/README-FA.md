# بازنویسی تمیز مافیای بلک

این پوشه نسخهٔ بازنویسی‌شده و آزمایشی است؛ نسخهٔ فعلی در ریشهٔ مخزن دست‌نخورده می‌ماند تا تست کامل شود.

## اصول طراحی
- رابط فارسی، راست‌چین و واکنش‌گرا با یک فایل CSS مشترک
- یک منبع وضعیت اتاق در Firebase Realtime Database از مسیر واسط Cloudflare یعنی `/api/db`
- اتاق با کد پنج‌رقمی و شناسهٔ پایدار برای هر عضو
- پیام‌های چت لابی در همان اتاق و همگام‌سازی تغییر وضعیت از طریق شنوندهٔ دیتابیس
- صندلی آزمایشی فقط برای تمرین گرداننده؛ بدون ربات خودکار و بدون ادعای حضور انسان واقعی
- اطلاعیهٔ قوانین پیش از ورود به بازی
- صدای گروهی WebRTC با رضایت صریح کاربر برای میکروفن و نشان دادن وضعیت اتصال

## وضعیت
این نسخه هنوز آزمایشی است و نباید به‌عنوان نسخهٔ عمومی منتشر شود. ابتدا باید اتصال دو مرورگر، همگام‌سازی اتاق، شروع بازی، چت، مجوز میکروفن و صدای دو گوشی آزمایش شوند. رابط فعلی به‌تنهایی تضمین نمی‌کند که تمام این آزمون‌ها پاس شده‌اند.

## چک‌لیست پذیرش
1. دو گوشی با کد یکسان دقیقاً یک اتاق و فهرست بازیکنان مشترک ببینند.
2. پیام چت در هر دو گوشی بدون تازه‌سازی ظاهر شود.
3. شروع بازی فقط برای گرداننده فعال باشد و وضعیت برای همه همگام شود.
4. قطع و وصل اینترنت موجب ساخت عضو تکراری نشود.
5. صندلی آزمایشی قابل افزودن و حذف باشد و در شمار انسان‌های واقعی جدا مشخص شود.
6. میکروفن فقط پس از اقدام کاربر فعال شود و قطع/خطای صدا واضح نمایش داده شود.
7. فایل‌های قدیمی یا آیکن‌ها تا زمانی که مرجعشان بررسی نشده حذف نشوند.
