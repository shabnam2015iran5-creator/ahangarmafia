# نسخه ۳۳
- اتاق انتظار: بدون نوار بالا، ۱۰ آواتار بزرگ + کارت گرداننده، پایین فقط خروج/میکروفن/آماده/شروع
- صفحه بازی: بدون آیکون‌های بالا؛ ذره‌بین + تایمر + نوار باریک؛ نفر ۹ و ۱۰ کامل دیده می‌شوند
- لایک/دیسلایک، طناب دار (رأی)، شیشه شکسته (شب)، علامت قطع اتصال روی عکس هر نفر
- حذف خودکار پس از ۱۵ دقیقه قطع اتصال (config.js: MAFIA_DISCONNECT_KILL_MIN)
- نوبت و شمارش معکوس، اعلام چالش، چت بسته/باز و چالش/توقف تایمر توسط گرداننده
- رفع باگ‌ها: قفل واقعی میکروفن بازیکنان، ۱۰مین صندلی لابی، اتصال وویس
- بنرهای «روز معارفه / روز N / شب / رأی‌گیری» برداشته شد؛ سؤال گرداننده/بازیکن در لابی دوستانه حالا روی همه‌چیز دیده می‌شود
- مهم: فایل peerjs.min.js را کنار index.html روی هاست بگذار تا وویس بدون CDN هم کار کند
